# local-restaurant-communication-agent (Burger Bot)
A prototype of a locally-run AI agent that automates fast food burger restaurant interactions through voice or messaging.

The specs of the computer that I used for this program:
 - Intel I5-12400F
 - RTX 3060 12GB
 - 16 GB of RAM DDR4
 - 1 TB of SSD

Libraries needed (the ones that needs to be installed):
  - uv (optional for making the environment)
  - torch
  - whisper
  - ollama
  - pydantic
  - numpy
  - sounddevice
  - kokoro

This AI agent is vibecoded with my supervision.
